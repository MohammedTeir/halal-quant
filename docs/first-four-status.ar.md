# حالة المراحل الأربع الأولى

متطلبات البرمجة واختبارات القبول الأصلية للمراحل 1–4 مطبّقة وناجحة. هذا يتيح
الانتقال إلى تطوير المرحلة الخامسة، ولا يعني اعتماد المشروع للتداول أو اعتمادًا شرعيًا.

| المرحلة | الجاهز | الحد المتبقي قبل اعتماد التشغيل/البحث |
|---|---|---|
| 1 — الأساس | API وقاعدة البيانات والترحيلات والصلاحيات والتشغيل وCI | مراقبة وتشغيل الإنتاج ضمن مراحل الإصدار اللاحقة |
| 2 — الاستراتيجيات | ثلاث استراتيجيات Python طويلة فقط، مع اختبارات السببية والتكاليف وإعادة الإنتاج | اختبار الربحية على بيانات معتمدة ضمن المرحلة السادسة؛ Pine اختياري |
| 3 — البيانات | أخبار وتقويم وأرباح وإجراءات الشركات ومصدر الذهب؛ فحص 12 شهرًا من 2025 مع حفظ المصدر والأثر | جدول جلسات موثّق لتفسير كل الفجوات واعتماد ملاءمة المصدر للبحث |
| 4 — الذكاء والقرار | مخرجات موثّقة واختبارات حقن وسياسات حتمية؛ v5 ينجح في 16/16 و8/8، واختبار التصنيفات البشرية الخارجية 30/30 | مراجعة ملاءمة المصادر والسياسات لنطاق التشغيل؛ العينة الصغيرة لا تثبت دقة عامة |

الفحص التفصيلي لأكتوبر أثبت أن التكرار يشمل 60 صفًا متطابقًا حرفيًا. أضيف خيار
معلن لإزالة النسخ المطابقة فقط، مع حفظ الأصل وبصمته والتوقيتات والعدد وبصمة المحذوف.
لا تُعدّل الأسعار أو التوقيتات، ويظل التكرار ذو القيم المختلفة مرفوضًا. السنة الناتجة
تحتوي 5,855 شمعة ساعة و1,263 شمعة أربع ساعات. سجل الرفض السابق محفوظ.

اختبار FinancialPhraseBank يستخدم التصنيفات البشرية الأصلية، ولم نغيّرها أو نعدّل
v5 بعد رؤية نتائجه. نجح 30/30، لكنه مخصص للبحث غير التجاري وفق ترخيص المجموعة،
ولا يمثل توقيع أصحاب التصنيفات على المشروع أو موافقة بشرية على قراراته.

الاختبارات الحالية: **334 ناجحة**. التداول معطل؛ المرحلة الخامسة، ثم بوابات البحث
والتداول الورقي، لازمة قبل أي ترقية. [تفاصيل الأدلة والقيود](completion-requirements.md).


## المراجعة التقنية المستقلة وتدقيق الجلسات

اختار المستخدم مساعدًا آخر للمراجعة التقنية المستقلة. اكتملت المراجعة وحكمها قبول
مشروط للبحث فقط؛ لا تمثل موافقة بشرية أو اعتمادًا للتداول. تحقق المراجع من الأدلة
والنتائج، وعولجت ملاحظتان منخفضتا الخطورة. ما زالت شروط هوية الناشر الأصلي، وربط
جدول جلسات الذهب بالمصدر والسنة، والتحقق التمثيلي من السياسات مفتوحة قبل التشغيل.

[تدقيق جلسات الذهب](gold-session-review.ar.md) يوثق كل الفجوات الـ300 ومقارنتها
بمرجع رسمي، دون اعتمادها إغلاقات مؤكدة لمصدر HistData. [المراجعة المستقلة](independent-technical-review-2026-10-29.md).
