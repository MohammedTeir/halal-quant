# المرحلة الخامسة: المنجز وحدود الاعتماد

أُنجزت البنية البرمجية لمسار الامتثال والمخاطر ضمن نطاق البحث، واجتازت **459 اختبارًا**
على مستوى المشروع. أُضيف 47 اختبارًا بعد الجزء الأول، وأغلق المراجع التقني المستقل
ست ملاحظات برمجية. حكم المراجعة قبول لمسار بحث محدود؛ لا يمثل فتوى أو اعتماد تداول.

يشمل التنفيذ الحالي:

- تخزين المراجعات والمناهج والسياسات وحالة المخاطر بإصدارات وسجل تدقيق ووقت استلام يحدده الخادم.
- صلاحيات منفصلة للمراجع ومشغّل المخاطر وقارئ الوسيط؛ محلل الأخبار لا يستطيع منح موافقات.
- حساب نسب الفحص وفق منهج يحدده المراجع، مع بقاء المنهج غير مختار افتراضيًا. سحب المنهج أو انتهاء المراجعة يمنع استخدام موافقة أقدم.
- قراءة الحساب والمراكز والأوامر والأنشطة وعرض السعر من Alpaca عبر الخادم فقط. لا يقبل المسار رفع أرصدة أو ملكيات من الطلب.
- حجز سعة بحثية داخل معاملة تمنع تجاوز الحدود بطلبات متزامنة، مع احتساب الرسوم والانزلاق والأوامر المعلّقة.
- حالة إيقاف محفوظة؛ يستطيع المشغّل تفعيلها، ويحتاج مسحها صلاحية المراجع. تُعاد مراجعة الضوابط عند تقييم القرار.
- فحص مستقل لخروج المملوك، وسجل مراجعة للأصل المملوك الذي تتغير أهليته، دون تصفية آلية أو افتراض حكم شرعي بالاحتفاظ.

نجحت قراءة فعلية من حساب Alpaca الورقي وعرض سعر IEX. الحساب المشاهد كان بلا مراكز
أو أوامر؛ لا تثبت هذه التجربة توافق أوامر فعلية أو تسويتها أو الحيازة. المصدر لم
يقدّم إثباتات الحساب النقدي والنقد المستقر وتعطيل الإقراض والاقتراض، فبقيت أعلامها
غير موثقة، وبقي الشراء محظورًا. لم يُرسل أو يُلغَ أي أمر.

للاعتماد الفعلي ما زال يلزم تحديد منهج ومراجع مؤهلين وإرفاق أدلة حقيقية للأصول
والحيازة، ومصدر يثبت النقد المستقر وشروط الحساب. هذه موافقات وحقائق خارجية لا
يمنحها وجود مفتاح API أو نجاح الاختبارات. المفاتيح الجديدة في `.env.example`
صلاحيات داخلية للتطبيق، وليست مفاتيح LLM إضافية، وهي معطّلة افتراضيًا حتى إعدادها.

نفّذ ترحيل قاعدة البيانات إلى `0006_controls` عند تشغيل النسخة الجديدة. لا تعيد
سجلات المعاينة الافتراضية إنشاء موافقات أو حقائق وسيط، ولا يمدد تكرار الطلب حجزًا
قديمًا. حجوزات البحث ليست أوامر وسيط. تبقى إدارة الأوامر والتسويات والمطابقة الذرية
واختبارات التداول الورقي ضمن المرحلة الثامنة، والتداول الفعلي معطّل.
